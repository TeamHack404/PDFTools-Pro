# PDFTools Pro

**Prototipo web desarrollado con fines académicos para el curso de Hacking Ético de la Universidad Peruana de Ciencias Aplicadas (UPC)**

## Descripción

PDFTools Pro es una aplicación web que simula una plataforma de herramientas para gestionar documentos PDF. Su interfaz presenta funcionalidades como unir, comprimir, convertir y proteger archivos, junto con una sección de descarga para Windows 11.

El sitio forma parte de un proyecto académico que busca demostrar los riesgos asociados a la descarga y ejecución de software aparentemente legítimo desde fuentes no confiables.



## Objetivo del proyecto

Desarrollar un escenario de laboratorio que permita analizar cómo la apariencia de una aplicación legítima puede influir en la decisión de descargar y ejecutar software, así como estudiar los riesgos relacionados con la captura no autorizada de entradas del teclado.

## Características de la página web

- Página principal de presentación de PDFTools Pro.
- Información sobre una versión de demostración para Windows 11.
- Botones de descarga del archivo de laboratorio.
- Vista previa ilustrativa de herramientas de gestión de PDF.
- Interfaz adaptable a distintos tamaños de pantalla.

## Tecnologías utilizadas

- **React:** desarrollo de la interfaz web.
- **TypeScript:** implementación de los componentes y lógica de la página.
- **Vite:** entorno de desarrollo y compilación.

## Instalación del entorno web

Para ejecutar la página localmente, se requiere Node.js y npm.

```bash
npm install
npm run dev
```

Después, abrir en el navegador la dirección local indicada por Vite.

## Alcance y limitaciones

PDFTools Pro es una simulación académica. La página web no realiza conversiones, compresiones ni modificaciones reales de archivos PDF.

El componente de captura de teclado pertenece a una prueba de concepto separada, desarrollada para ejecutarse únicamente en un entorno controlado y utilizando datos ficticios.

El proyecto no está destinado a recopilar información de usuarios reales ni a distribuir software para su ejecución sin autorización.

## Uso académico

Este proyecto fue desarrollado exclusivamente con fines educativos para estudiar los riesgos asociados al software no confiable y promover buenas prácticas de seguridad informática.
